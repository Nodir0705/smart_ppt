Beyond rereading suspect rows on one handout, the checker grades a whole class with a single command.
First, point it at a folder of scans, each named after its student, and every model loads once.
Next, a class report lists each student's total and per-exercise scores, revealing which question the class struggled with.
One corrupt scan never stops the batch.
Finally, every stage is cached to disk, so changing the answer key regrades real handouts in seconds.
