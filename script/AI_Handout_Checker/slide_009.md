So far we have followed a single handout through the checker, but at classroom scale a teacher can grade the whole class with just one command.
First, you point it at a folder of scans, each A I model loads only once and grades every student, and the file name tells it whose handout it is.
Then it writes a class weak spot report, a C S V file with each student's total and a score for every exercise.
That shows you right away which question the class struggled with, and a single corrupt scan never stops the rest of the batch.
Finally, every stage is cached to disk, so regrading a page it has already seen takes seconds instead of minutes, and if you change the answer key, only the affected work runs again.
