Once the handout has been read, stage B does the grading, and the rule here is simple: the A I reads, and Python decides.
First, the grader splits the page into separate exercises and tags each one by type, whether it's fill in the blank, choosing the right sentence, or circling a word.
Then, for every item, it pulls out what the student actually wrote and lines it up against the expected answer.
Next, Python owns the score, recomputing correctness by text overlap, so the same answer always earns the same mark instead of depending on the model's whim.
Finally, an optional answer key overrides the model on any item, and borderline answers get flagged for a teacher to review rather than guessed.
We hand scoring to Python because a language model is great at reading, but a grade must be consistent, so the model only reads and fixed rules do the counting, which means every mark can be checked, tested and trusted before it goes back onto the page.
