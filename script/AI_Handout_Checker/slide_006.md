Once the handout is read, stage B grades it, with the AI reading and Python deciding.
First, the page is split into exercises, each labelled by type, like fill in the blank.
Then the model extracts what each student wrote and compares it to the expected answer.
Next, Python scores it with fixed rules, so the same page always gets the same mark.
Finally, an optional answer key overrules the model, and borderline answers are flagged, not guessed.
