With the scores settled, stage C has one job left, which is putting those marks back on the handout right next to the answers they belong to.
First, a layout pass finds the exact line each answer sits on, and it splits multi column pages so two columns never blur into one.
Next, each graded item is matched to its row by the sentence text itself, because the scan often drops the question numbers.
Finally, the system draws the verdict, a red tick or cross with the correct answer beside it, and any note it cannot place goes into a list at the bottom of the page.
You can see the result on this worksheet, where present perfect gets a red cross with have been written in, and past continuous gets an orange question mark suggesting was working.
And when the fast first pass may have misread an answer, there is a cheap way to recover it, which is where we go next.
